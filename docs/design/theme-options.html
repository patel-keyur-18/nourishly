Five directions for how Nourishly should look

Each option below is a complete token set — surfaces, ink, accent, and the four macro colours — shown on the same dashboard so you are comparing the theme and nothing else. The toggle switches every preview between its light and dark variant at once.

The data is a plausible Thursday: thepla and chaas for breakfast, a rotli-dal-shaak lunch, dinner still to log.

All ten palettes are validated, not eyeballed. Every theme's four macro hues passed colour-blindness separation, chroma, lightness-band and contrast checks in both light and dark — so the choice below is purely about character. Nothing here is a compromise on legibility.

How to choose

Who opens it most?

If someone in the house wants two numbers and no jargon, the quieter themes carry less visual noise per glance.

→ Kora or Indigo

When is it opened?

Logging happens right after eating — often at night. If most logging is after dark, pick the theme whose dark mode was designed first.

→ Nilgiri

Should it feel like food?

Only one option takes its palette from the kitchen rather than from software convention. That is either the point or a distraction.

→ Haldi

Want zero surprises?

The conventional choice is conventional because it works. No one will ever be confused about what the app is for.

→ Neem

Whichever you pick, these hold: the macro tick marks show your target, so a bar is read against a goal rather than filled to an edge. Over-target is never red — above uses a violet, deliberately, because a food tracker should not scold. Every status carries a label and a dot, never colour alone. And the score is withheld when coverage is too thin — the 58% covered chip is that rule showing its work.
